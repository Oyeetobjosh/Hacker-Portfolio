Mission Objective

The objective: map the EVM state constraints locally via Foundry, identify an architectural bypass, and discover an explicit, programmatic rescue pathway without upgrading the logic.

The Discovery: Chronological Deadlock

The root cause was a multi-tier chronological loop deadlock within the getState() view function.

  • Sequential tiers are tightly coupled by state invariants.
  • An administrative parameter update pushed Tier 1's endsAt timestamp past Tier 2's startsAt.
  • This caused a temporal collision when iterating through joinedCrowdsales[].
  • getState() panicked/reverted, causing core functions like refunds and withdrawals to permanently fail.
