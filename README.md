# tobjosh - Hacker Portfolio

Interactive terminal-style portfolio for tobjosh, the nemesis of security. 

## Features
- **Interactive CLI:** Fully functional bash-like experience.
- **Command History:** Use `Up` and `Down` arrows to navigate previous commands.
- **Integrated Arsenal:** Display of offensive security tools and workflows.
- **Case Studies:** Empirical breakdowns of smart contract vulnerabilities.
- **SignalDesk:** Local, permission-first lead research, message drafting, manual-send tracking, goal tracking, and focus sessions.
- **Custom Tooling:** Includes a custom Python script for web app reconnaissance.
- **Easter Eggs:** Custom CSS animations including a hidden "pwned" background.

## Usage
Open `index.html` and type `help` to see the available terminal commands. Type `outreach` to launch SignalDesk. SignalDesk stores workspace data only in the current browser and never sends social messages automatically.
